# @chatwoot-next/channels

This package provides adapters for the 13 messaging channels Chatwoot supports, mirroring the STI subclasses under `app/models/channel/` (api, email, facebook_page, instagram, line, sms, telegram, tiktok, twilio_sms, twitter_profile, web_widget, whatsapp, plus the Enterprise-only `voice` channel) and the per-channel service trees under `app/services/<channel>/`. Each adapter implements `verifyWebhookSignature`, `parseInbound`, `sendOutbound`, and `setupChannel`; **webhook signature verification must remain byte-compatible with the current Rails implementation** so that providers (Meta, Twilio, 360dialog, Line, Telegram, TikTok, etc.) do not retry-storm us during cutover. WhatsApp follows a three-provider abstraction (`cloud`, `dialog360`, plus the existing `WhatsappBaseService` interface) that mirrors `app/services/whatsapp/providers/`, with `pickProvider(channel)` selecting the correct backend from the channel's `provider` column.

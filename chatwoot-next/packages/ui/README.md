# @chatwoot-next/ui

Shared React design system for the Chatwoot Next stack. Ports the Vue components living under `app/javascript/dashboard/components-next/` to Tailwind-only React (no scoped/custom CSS), exposing primitives like Button, Avatar, Badge, Banner, Breadcrumb, Dialog, Dropdown, Input, and Tabs along with the `cn` class-merging helper.
